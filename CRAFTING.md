# Crafting Materials — Reference

## Crafting Chains

```
pelt       ──┐
cow_hide   ──┤── (tanning) ──→  leather
rabbit_pelt──┘

yarn  ── (spinning) ──→  thread  ── (weaving) ──→  cloth

feathers  ─→  (end product / ingredient)
string    ─→  (end product / ingredient)
```

**Raw drops** (obtained by killing animals): pelt, cow_hide, rabbit_pelt, yarn, feathers, string  
**Craft only** (never drop): leather, thread, cloth

---

## Colors (14 total)

`red · orange · yellow · green · blue · lilac · purple · turquoise · pink · lime · amber · brown · black · white`

All 14 colors exist for every material. Color is random on drop.

|---|---|

| Turtle | pelt |
| Deer | string |
