# Goat Sprites

Goat Baby and Female are **strip36**; Goat Male is **strip32** (one fewer source row).
Frame size is 32×32 px for all variants.

## Frame Layout — strip36 (Baby, Female) — 1152×32 px

| Frames | Count | Description |
|--------|-------|-------------|
| 0 – 3  | 4 | Walk Left (original row 0) |
| 4 – 7  | 4 | Walk Right (row 0 mirrored) |
| 8 – 11 | 4 | Walk Down (row 1) |
| 12 – 15 | 4 | Walk Up (row 2) |
| 16 – 19 | 4 | Idle Right (original row 3) |
| 20 – 23 | 4 | Idle Left (row 3 mirrored) |
| 24 – 27 | 4 | Idle Type 1 (row 4) |
| 28 – 31 | 4 | Idle Type 2 (row 5) |
| 32 – 35 | 4 | Idle Type 3 (row 6) |

## Frame Layout — strip32 (Male) — 1024×32 px

## Source Files

Baby/Female source: 128×224 (4 cols × 7 rows, 28 frames).
Male source: 128×192 (4 cols × 6 rows, 24 frames).
Rows 0 and 3 were mirrored to generate the opposite-facing animations (+8 frames).
Generated by `tools/process_chicken_sprites.js`.
